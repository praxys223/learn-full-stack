Під час практичних занять ви верстатимете лендінг. Макет сторінки міститься у файлі .fig у папці з матеріалами практики.

Щоб ускладнити завдання, зробіть сторінку адаптивною: вона має охайно виглядати і на широкоформатному моніторі, і на мобільному пристрої.

Файл .fig — це файл Figma. Figma — хмарний інструмент для створення інтерфейсів користувача (UI), проєктування користувацького досвіду (UX) і прототипів. Він дає змогу дизайнерам працювати над проєктом спільно в реальному часі. У Figma можна створювати векторну графіку, інтерактивні прототипи й макети як у вебверсії, так і в програмі для комп’ютера.

Як відкрити файл .fig:
	1. У Figma:
	   • Файли .fig використовують для обміну макетами та їх імпорту.
	   • Щоб відкрити файл .fig, скористайтеся вебверсією Figma або програмою для комп’ютера.
	2. Порядок дій:
	   • Перейдіть на сайт Figma й увійдіть у свій обліковий запис.
	   • За потреби натисніть New File («Новий файл») у верхньому правому куті, щоб створити новий проєкт.
	   • Перетягніть файл .fig у вікно браузера або імпортуйте його через меню File → Import… («Файл» → «Імпортувати…») у вебверсії чи програмі для комп’ютера.
	3. Після імпорту файл відкриється у вашому робочому просторі Figma. Ви зможете працювати з ним як зі звичайним проєктом.

Як скопіювати зображення з проєкту Figma:
	1. Скопіювати до буфера обміну:
	   • Відкрийте проєкт Figma, у якому міститься зображення.
	   • Виберіть зображення або фрейм із потрібним зображенням.
	   • Натисніть Ctrl + C (Windows) або Cmd + C (Mac).
	   • Вставте зображення до іншого проєкту Figma, документа чи програми за допомогою Ctrl + V (Windows) або Cmd + V (Mac).
	2. Експортувати зображення:
	   • Виберіть зображення або фрейм із ним.
	   • Натисніть правою кнопкою миші та виберіть Export («Експортувати»).
	   • У меню експорту виберіть формат (наприклад, PNG або JPG) і параметри експорту.
	   • Натисніть Export («Експортувати») і збережіть файл на пристрої.
