# Project instructions

## About the learner

The project owner is learning programming. Keep solutions clear and appropriate for the current lesson. When helping with homework, explain important choices in simple terms so the owner can understand and learn from the code.

## Project folders

- `reference/` contains lesson materials provided by the owner. Read the relevant materials before working on a lesson or homework assignment. Treat them as source material; do not edit them unless asked.
- `img/` contains images and other visual assets used in the project. Reuse relevant assets from this folder and reference them with correct relative paths.
- `home-woek/` is the existing homework folder (keep this spelling unless the owner asks to rename it). Create a separate subfolder for each homework assignment, such as `home-woek/homework-01/`.

## Homework rules

- Put every task in an assignment in its own HTML file and its own CSS file. For example, use `task-01.html` and `task-01.css`, then `task-02.html` and `task-02.css`.
- Link each HTML file to its matching CSS file with a relative `<link rel="stylesheet" href="task-01.css">` element.
- Keep each task's code independent and easy to open in a browser.
- Use English for all new file and folder names, code identifiers, comments, and documentation. Write project documentation in English.
- Follow the requirements and techniques in the corresponding lesson materials. Do not introduce unnecessary complexity beyond the lesson's scope.
